# surprise-environment OPIc Scripts

재활용·환경·집안일·커뮤니티 돌발 질문을 아파트 분리수거라는 하나의 세계관으로 묶은 OPIc 스크립트입니다.

## 공통 암기 전략

- 공통 흐름은 `Wednesday cleaning -> separate waste -> check labels -> sorting mistake -> manager's help`로 고정한다.
- 묘사와 습관에서는 깨끗하고 사용하기 쉬운 분리수거장에 집중한다.
- 과거 경험에서는 더러운 플라스틱 용기를 잘못 버린 실수 하나만 말한다.
- 비교에서는 `few unclear bins -> separate bins with pictures`만 대비한다.
- 롤플레이에서는 대형 폐기물 스티커 문제를 설명하고 해결책 두 가지를 묻는다.

## 만능 문장 묶음

- `It is not large, but it is clean and easy to use.`
- `I separate the trash before taking it outside.`
- `At first, I felt embarrassed, but the manager helped me.`
- `Since then, I check the label carefully.`
- `The current system is better for our community.`
