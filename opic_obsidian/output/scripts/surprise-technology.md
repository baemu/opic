# surprise-technology OPIc Scripts

휴대폰·인터넷·기술/AI·컴퓨터·전자제품 돌발 질문을 `무선 이어폰과 스마트폰의 연결 문제를 직접 점검한 뒤 보증 교환`이라는 하나의 경험으로 묶은 스크립트입니다.

## 공통 세계관과 주제 교체

- `휴대폰:` smartphone, messages, maps
- `인터넷:` streaming, Wi-Fi/Bluetooth connection
- `기술/AI:` an AI assistant app on my smartphone
- `컴퓨터:` laptop, pairing the earbuds with another device
- `전자제품:` wireless earbuds, battery, service center, warranty
- 모든 문제 경험은 `재시작 -> 연결 해제/재연결 -> 다른 기기로 테스트 -> 기기 결함 판단 -> 보증 교환` 순서로 말한다.
