# surprise-health-personal OPIc Scripts

건강·병원·치과·미용실·패션 돌발 주제를 `온라인 예약 -> 방문 준비 -> 작은 일정 문제 -> 직원 도움 -> 재확인`이라는 한 세계관으로 묶은 공통 경험 스크립트입니다.

## 공통 암기 전략

- 장소와 사람만 바꾼다: `clinic / doctor`, `dental clinic / dentist`, `hair salon / stylist`, `clothing store / store clerk`.
- 예약 이름만 바꾼다: `checkup / dental cleaning / haircut / styling consultation`.
- 준비물만 바꾼다: `ID and symptoms / tooth pain note / style photo / preferred size and color`.
- 모든 문제 경험은 `wrong time -> polite call -> another opening -> new confirmation`으로 해결한다.
- 한 답변에서는 건강, 치과, 미용실, 패션을 모두 나열하지 않고 질문에 맞는 한 장소만 선택한다.

## 만능 문장 묶음

- `I usually make an online appointment before I visit.`
- `I check the date, time, and location one more time.`
- `At first, I felt embarrassed and worried.`
- `Luckily, the staff found another open time for me.`
- `Please send me a new confirmation message.`
