# surprise-bank OPIc Scripts

은행·ATM·모바일뱅킹·결제 문제를 가까운 은행과 모바일 앱이라는 공통 세계관으로 묶은 돌발 대비 스크립트입니다.

## 공통 암기 전략

- 공통 소재는 `bank near the subway -> mobile banking -> app problem -> ATM solution -> double-check`로 고정한다.
- 은행 묘사는 크기보다 접근성과 친절함에 집중한다.
- 과거 경험은 월세 이체 직전 앱이 작동하지 않았던 일 하나만 쓴다.
- 비교는 `branch and paper forms -> smartphone app`만 대비한다.
- 롤플레이는 `block the card -> check transactions -> get a new card`로 외운다.
