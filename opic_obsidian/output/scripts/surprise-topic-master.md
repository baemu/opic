# OPIc 돌발주제 전체 대비 Master Map

돌발 주제 전체를 9개의 공통 세계관과 5개의 답변 구조로 압축한 학습 순서표입니다.

## 사용하는 순서

1. 질문에서 주제 단어를 잡는다.
2. 질문 유형을 고른다.
   - `Describe / What is it like` -> Type 1 Description
   - `usually / normally / often` -> Type 2 Habit
   - `a time / happened / memorable / problem` -> Type 3 Past Experience
   - `compare / changed / past and now` -> Type 4 Comparison
   - `call / ask / explain / solve` -> Type 5 Role Play
3. 아래 표에서 주력 세계관을 고른다.
4. 첫 문장과 핵심 명사만 실제 주제에 맞게 바꾼다.
5. 감정, 해결 흐름, 마무리는 그대로 재사용한다.

## 세계관별 핵심 기억 흐름

### 1. 환경

`Wednesday evening -> sort plastic/cans/paper -> one sorting mistake -> staff helped -> check labels now`

### 2. 날씨·교통

`heavy rain -> bus/subway delay -> check app -> use another route -> prepare earlier now`

### 3. 기술

`use device every day -> one side/connection stopped -> restart and reconnect -> service center -> warranty replacement`

### 4. 예약

`book on phone -> wrong date -> embarrassed -> staff changed it -> double-check now`

### 5. 은행

`send important payment -> app would not load -> call bank -> use ATM -> never wait until the last day`

### 6. 건강·개인서비스

`make appointment online -> visit nearby place -> small schedule/problem -> staff suggested another option -> confirm details now`

### 7. 가족·행사

`small dinner plan -> prepare food together -> one person got sick -> change date or share food -> still felt close`

### 8. 가구·가전

`buy online -> product arrived damaged/noisy -> call store -> repair or replacement -> check delivery carefully now`

### 9. 산업·사회 변화

`shopping app -> fast delivery -> packaging waste -> delivery problem -> buy carefully and recycle`

## 공통 문장 교체표

| 기본 문장 | 주제별 교체 예시 |
|---|---|
| `It is not fancy, but it has everything I need.` | bank, clinic, device, furniture, public place |
| `I usually do this once or twice a week.` | banking, recycling, shopping, healthy routine |
| `At first, I felt worried, but luckily, the problem was solved.` | 모든 문제 경험 |
| `Since then, I always double-check the details.` | 예약, 은행, 병원, 쇼핑, 교통 |
| `The biggest difference is convenience.` | 기술, 은행, 산업, 교통, 예약 |
| `Could you please check it for me?` | 모든 문의형 롤플레이 |
| `If that is not possible, could I get another option?` | 모든 문제 해결형 롤플레이 |

## 주제 전환 시 반드시 바꿀 것

- 첫 문장에 실제 질문의 주제 단어를 넣는다.
- 장소나 물건 이름을 바꾼다.
- 문제 해결 방법을 해당 주제에 맞게 바꾼다.
  - 예약: 변경·환불
  - 물건: 수리·교환
  - 은행: 정지·재발급
  - 교통: 다른 노선·시간 변경
  - 건강: 재예약·다른 진료 시간
- 감정과 결론은 대부분 그대로 재사용해도 된다.
- 연결되지 않는 주제로 억지 전환하지 않는다.

## 최소 암기 방법

- 45개 답변 전체를 통암기하지 않는다.
- 각 세계관의 `[암기 포인트]` 세 문장만 먼저 외운다.
- Type 3 과거 경험과 Type 5 롤플레이를 가장 먼저 연습한다.
- Type 1·2·4는 같은 명사와 경험을 현재형·과거형으로 바꿔 말한다.
- 무작위 질문을 들은 뒤 `주제 -> 세계관 -> Type -> 첫 문장`을 5초 안에 고르는 연습을 한다.
