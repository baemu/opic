# surprise-industry-trends OPIc Scripts

산업·사회 변화·온라인 쇼핑·패션·환경 문제를 온라인 쇼핑과 배송 산업이라는 공통 세계관으로 묶은 돌발 대비 스크립트입니다.

## 공통 암기 전략

- 공통 흐름은 `shopping app -> fast delivery -> packaging waste -> delivery problem -> check carefully`로 고정한다.
- 산업 질문은 온라인 쇼핑과 배송 한 가지로 좁힌다.
- 패션 질문에서는 `item/product`를 `clothes/jacket`으로 바꾼다.
- 환경 질문에서는 편리함보다 포장 쓰레기와 재활용 행동을 강조한다.
- 어려운 사회 질문도 `편리함 한 가지 + 문제 한 가지 + 내 행동 한 가지`로 끝낸다.
