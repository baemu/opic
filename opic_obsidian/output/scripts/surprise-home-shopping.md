# surprise-home-shopping OPIc Scripts

가구·가전·쇼핑·집안일 돌발 질문을 `온라인으로 소파나 가전을 주문하고, 문제를 발견한 뒤 고객센터를 통해 교환`하는 하나의 경험으로 묶은 스크립트입니다.

## 공통 세계관과 주제 교체

- `가구:` a gray sofa, a loose leg, the living room
- `가전:` a cordless vacuum, a weak battery, a strange noise
- `쇼핑:` online order, reviews, delivery, receipt, exchange
- `집안일:` Saturday cleaning, vacuuming, checking loose parts
- 모든 문제 경험은 `도착 즉시 확인 -> 사진 촬영 -> 고객센터 연락 -> 수리 대신 교환 요청 -> 새 제품 수령` 순서로 말한다.
